# Creación de una solución de minería de conocimientos con Azure AI Search

- https://aka.ms/mslearn-ai-knowledge-mining

# 1. Azure AI Search (Former Azure Cognitive Search)
- Puede indexar documentos y datos de varios orígenes.
- Uso de habilidades de IA para enriquecer datos de índice.
- Almacenamiento de conclusiones extraídas en un almacén de conocimiento para su análisis e integración.
## 1.1 Aplicaciones de Azure AI Search
- Implementación de una solución de motor de búsqueda Enterprise Search.
- Compatibilidad con la generación aumentada de recuperación (RAG) para mejorar las capacidades de búsqueda y respuesta.
- Creación de soluciones de minería de conocimiento.

## 1.2 Extracción de datos con un indexador
- Un indexador extrae datos de un origen de datos.
- Automatiza ingesta de datos.
- Descifrado de documentos.

## 1.3Enriquecimiento de datos extraídos.
- AI Skills
- Detección de idioma en que está escrito un texto.
- Extracción de entidades como personas, lugares, organizaciones.
- Extracción de frases clave.
- Análisis de sentimientos.
- Traducción de texto a otro idioma.
- Reconocimiento óptico de caracteres (OCR) para extraer texto de imágenes.

## 1.4 Búsqueda de un índice
- Cada campo de índice se puede configurar como:
  - **Key**: Identificador único para cada documento.
  - **Searchable**: Permite que el campo sea buscado.
  - **Filterable**: Permite que el campo sea utilizado para filtrar resultados.
  - **Sortable**: Permite que el campo sea utilizado para ordenar resultados.
  - **Facetable**: Permite que el campo sea utilizado para crear facetas en los resultados de búsqueda.
  - **Retrievable**: Permite que el campo sea devuelto en los resultados de búsqueda.
- Se pueden realizar consultas de búsqueda utilizando el lenguaje de consulta de Azure AI Search.

## 1.5 Conservación de la información extraída en un almcén de conocimiento

Almacenar proyecciones en Azure Storage
- **Objecto**: documentos JSON.
- **Tablas**: esquema relacional para campos extraídos.
- **Archivos**: imágenes extraídas.
